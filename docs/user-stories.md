# User Stories

## Epic A: Report a gap
- US-01 (P0): As a store user, I want to create a shelf-gap case so the observation is recorded.
- US-02 (P0): As a store user, I want to record the SKU and exact location so others can identify the affected product.
- US-03 (P0): As a store user, I want to record unknown information without guessing.

## Epic B: Investigate
- US-04 (P0): As a store user, I want to record shelf and back-room checks so physical availability is distinguished from system stock.
- US-05 (P0): As a store user, I want to record available inventory/order/delivery information so the case is evidence-based.
- US-06 (P0): As a store user, I want the system to suggest relevant next checks and explain why they are suggested.
- US-07 (P0): As a supervisor, I want provisional and confirmed causes to be clearly distinguished.

## Epic C: Act and verify
- US-08 (P0): As a supervisor, I want to assign an action and owner so responsibility is clear.
- US-09 (P0): As a store user, I want to update the action status so progress is visible.
- US-10 (P0): As a supervisor, I want a follow-up check before a case is marked resolved so closure is evidence-based.
- US-11 (P1): As a supervisor, I want to escalate overdue or blocked cases.

## Epic D: Learn
- US-12 (P0): As an analyst, I want a dashboard of cases and resolution outcomes so recurring problems can be investigated.
- US-13 (P1): As an analyst, I want to filter and export cases so I can analyse patterns.
- US-14 (P1): As a product owner, I want to see data quality limitations so metrics are not misinterpreted.

## Epic E: Trust and usability
- US-15 (P0): As a user, I want the app to be usable on a phone so I can record checks in store.
- US-16 (P0): As a user, I want clear error and empty states so I know what to do next.
- US-17 (P0): As a portfolio reviewer, I want sample data clearly labelled as fictional.
