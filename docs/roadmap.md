# Product Roadmap

This roadmap is a proposed sequence, not a commitment based on validated estimates.

## Phase 0: Discovery and framing
**Deliverables**
- Problem brief.
- Stakeholder map.
- Interview guide.
- Assumptions and risks.
- Existing workflow map.

**Exit criteria**
- Evidence of a real, recurring problem.
- Clear user and workflow selected.
- Confirmation that a separate tool may add value.

## Phase 1: Prototype
**Deliverables**
- Mobile-first clickable or working form.
- Synthetic cases.
- Guided investigation logic.
- Basic case statuses.

**Exit criteria**
- Users understand the flow.
- Unknown and conflicting evidence are handled safely.
- Core flow can be completed without coaching.

## Phase 2: MVP
**Deliverables**
- Persistent case storage appropriate to the chosen demo stack.
- Action assignment and verification.
- Dashboard and KPI definitions.
- Unit and workflow tests.
- Setup instructions.

**Exit criteria**
- End-to-end acceptance criteria pass.
- Data and limitations are documented.

## Phase 3: Pilot preparation
**Deliverables**
- Baseline measurement plan.
- Pilot protocol.
- Training and feedback prompts.
- Privacy/security review.
- Comparison design.

**Exit criteria**
- Permission and data access are approved.
- Pilot users and measures are agreed.
- No unsupported claims are made.

## Phase 4: Learn and iterate
**Deliverables**
- Findings from user tests.
- Usability issues.
- Metric results with limitations.
- Prioritised backlog.

**Exit criteria**
- Evidence-based decision to iterate, pivot, or stop.
